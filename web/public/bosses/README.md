# ボス画像の置き場所

このフォルダに以下のファイル名(PNG推奨、正方形に近い比率)を置くと、自動的にレイド画面で
絵文字の代わりに表示されます。ファイルが無いボスは絵文字表示のままになります。

| ファイル名        | ボス                         |
| ------------------ | ---------------------------- |
| `gehenna.png`       | 業火の悪魔ゲヘナ             |
| `lilith.png`        | 氷結の女王リリス             |
| `varga.png`         | 深淵の竜王ヴァルガ           |
| `voltex.png`        | 暴風の魔人ヴォルテクス       |
| `arachne.png`       | 深淵の蜘蛛女王アラクネ       |
| `shade.png`         | 闇の魔導士シェイド           |

配置後は特に設定不要で反映されます(ビルドし直すだけでOK)。
